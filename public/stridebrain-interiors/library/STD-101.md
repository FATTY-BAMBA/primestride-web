# Horizon Atelier Company Rule · Change Approval
STD-101 · v1.3 · Fictional approved demo policy

1. Record a customer change against project ID and current approved drawing.
2. Find the source scope, confirmed supplier quote and cost assumptions.
3. Check structural/site feasibility, material availability and delivery impact.
4. Calculate price using STD-102; owner approves customer commercial terms.
5. Obtain written customer acceptance and issue a controlled document revision.
6. Create work and procurement instructions only after all approvals.
7. Preserve actor, time, supporting sources and changed fields in an audit record.

A draft drawing cannot replace the approved construction issue. If a material quote or customer sign-off is missing, leave the request PENDING. Example CHG-101-QZ is not authorized at initial state.
