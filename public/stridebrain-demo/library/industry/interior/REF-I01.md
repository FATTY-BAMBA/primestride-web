# 室內裝修行為是否適用法規 / Determine whether works fall under interior-renovation rules

Reference ID: REF-I01
Category: LEGAL_SCOPE
Workflow phase: Intake & compliance
Source status: CURATED PUBLIC INDUSTRY REFERENCE (not company-specific)
Last verified: 2026-10-18

## Evidence-based explanation
The regulatory definition covers certain fixed ceiling, internal wall, partition and layout works; excluded examples include wallpaper, furniture placement and some movable elements. Building use and scope affect whether review requirements apply.

## Suggested controls for the StrideBrain demo
- Describe building use and location
- Identify fixed partitions, ceiling or wall works
- Record original floor plans and intended changes
- Request qualified professional determination for applicability

## Questions StrideBrain should ask
- Are internal walls or fixed partitions changing?
- Does the work affect an escape route or shared facility?

## Scope and uncertainty
Do not claim every residential decorative change requires the same permit; do not claim any project is automatically exempt.
