# 印刷委託與工單建立 / Print inquiry and job-ticket intake

## Evidence-based explanation
Prepress planning includes job-ticket preparation, artwork checks, imposition and cost estimates. As a model workflow, collect print size, quantities, stock, colors, finishing and due date before pricing.

## Suggested controls for the StrideBrain demo
- Require finished size and run quantity
- Capture single/double sided and color details
- Select paper/finish/binding
- Link promised delivery to job capacity confirmation

## Questions StrideBrain should ask
- Is this a new print run or a reprint?
- What quantity, substrate and finishing are required?
