# A3 海報尺寸與出血 / A3 trim and 3 mm bleed example

## Evidence-based explanation
An A3 trimmed poster is shown by one Taiwan provider as 297 × 420 mm, with 303 × 426 mm file dimensions including 3 mm bleed around each edge.

## Suggested controls for the StrideBrain demo
- Record trim versus artwork size separately
- Compare width/height in millimeters
- Flag insufficient bleed for preflight review
- Check orientation and safe margins

## Questions StrideBrain should ask
- Is 297 × 420 mm the requested finished size?
- Does the press-ready PDF measure 303 × 426 mm if using this 3 mm specification?

## Scope and uncertainty
Do not apply this rule to books, packaging dies or all commercial prints.
