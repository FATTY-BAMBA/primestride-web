# 色彩模式與色差說明 / Color-management guidance versus mandatory checks

Reference ID: REF-P04
Category: VENDOR_EXAMPLE
Workflow phase: Prepress
Source status: CURATED PUBLIC INDUSTRY REFERENCE (not company-specific)
Last verified: 2026-10-18

## Evidence-based explanation
Taiwanese vendor guidance recommends CMYK for color work and grayscale for mono work while explaining that RGB files may still be printed after conversion, potentially with different visual results.

## Suggested controls for the StrideBrain demo
- Record color space and desired match tolerance
- Offer physical or calibrated proof where appropriate
- Explain conversion risks to customer
- Preserve customer-approved proof version

## Questions StrideBrain should ask
- Is color accuracy important enough to require a proof?
- Is the CMYK recommendation a contractual requirement for this printer?

## Scope and uncertainty
Do not universally reject RGB files or promise exact color matching.
