# Taiwan interior SME workflow — curated playbook

Source type: MODELLED_WORKFLOW (not a company's real SOP)
Date reviewed: 2026-10-18

## 1. Lead intake

Input: Client request: residence type, floor, location, timeline, priorities

Output: Register inquiry, contact permission and missing requirements

Review gate: Never advance to an irreversible/customer-facing action if required source or approval is missing.

Cited industry reference IDs: REF-I01, REF-I11

## 2. Site and regulatory screening

Input: Building use, fixed partitions, safety, existing approved plans

Output: Open design/regulatory questions for qualified professional

Review gate: Never advance to an irreversible/customer-facing action if required source or approval is missing.

Cited industry reference IDs: REF-I01, REF-I02, REF-I10

## 3. Design and plan issue

Input: Measured plans, current drawings, finishes, material specs

Output: Version-controlled design drawing register and client review

Review gate: Never advance to an irreversible/customer-facing action if required source or approval is missing.

Cited industry reference IDs: REF-I03, REF-I04, REF-I07

## 4. Budget and proposal

Input: Approved scope, quantities, cost code assumptions

Output: Price preview, risk/exclusions and correct contract template

Review gate: Never advance to an irreversible/customer-facing action if required source or approval is missing.

Cited industry reference IDs: REF-I05, REF-I12

## 5. Contract and approval

Input: Design-only / build-only / combined scope, staged payments

Output: Signed scope and owner-approved handoff

Review gate: Never advance to an irreversible/customer-facing action if required source or approval is missing.

Cited industry reference IDs: REF-I05, REF-I08

## 6. Procurement and trade coordination

Input: Approved specs, measured quantity, suppliers, subcontractors

Output: Purchase/material request and scheduled work tasks

Review gate: Never advance to an irreversible/customer-facing action if required source or approval is missing.

Cited industry reference IDs: REF-I02, REF-I07, REF-I08

## 7. Site execution and inspection

Input: Issued drawings, daily progress, safety and exception records

Output: Tracked work, variation requests and corrective actions

Review gate: Never advance to an irreversible/customer-facing action if required source or approval is missing.

Cited industry reference IDs: REF-I04, REF-I07

## 8. Variation and client communication

Input: Material change, revised supplier quote, current drawing

Output: Separate change-order, customer response draft and approvals

Review gate: Never advance to an irreversible/customer-facing action if required source or approval is missing.

Cited industry reference IDs: REF-I08, REF-I07, REF-I11

## 9. Handover and post-project knowledge

Input: Inspection, defect list, acceptance, reconciled costs

Output: Reviewed closeout, client handover and reusable cost evidence

Review gate: Never advance to an irreversible/customer-facing action if required source or approval is missing.

Cited industry reference IDs: REF-I09, REF-I08
